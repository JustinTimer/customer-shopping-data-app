# customer-shopping-data-app
This project is a web application built with HTML and JavaScript that processes customer shopping data generated using Apache Spark. It provides functionality to add, update, and delete records, as well as export the dataset as a CSV file.


Documentation in English:

The HTML file was opened using VS Code with Live Server in order to automatically fetch the CSV file.
If the Live Server extension is not already installed, you can find it here:
https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer

Execution Instructions:
Open VS Code
Open the folder "customer-data-app"
Click on the file "front end" to open it
Right-click inside the "front end" file and select "Open with Live Server"
Features:
Add Record Button
Requires all form fields to be filled in, validates the input types, and appends the new record to the end of the dataset.
Edit Existing Records
Records can be edited by clicking on them.
Download Data as CSV
Allows downloading the dataset as a CSV file named "new_customer_shopping_data.csv".

Finally, the code includes comments that explain its functionality.
